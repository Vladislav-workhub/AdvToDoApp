#TO DO App для портфолио студентов
Учебное настольное приложеение для простого управления задачами на Java Swing.

## Возмоности
- Создание списка задач с возмжностью использования
расширенных комментариев.
- Автоматическое указывание даты и времени всех важных операций
внутри приложения
